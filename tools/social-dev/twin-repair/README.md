# TwinRepair

`TwinRepair` is the R2 Roslyn-backed repair factory for the corrected R1.5.1 whole-corpus queue.

The original C# source root is read-only. The factory mirrors only the target closure into the ignored `artifacts/r2-reference-twin/` tree, parses each source file once per batch, applies only explicit syntax-node transforms, and emits queue/status/provenance evidence.

The machine has no installed `dotnet` SDK. The local bundled PowerShell .NET 10 runtime exposes Roslyn 5.0 assemblies, so `twin-repair.ps1` compiles these C# sources through `Microsoft.CodeAnalysis.CSharp.CSharpCompilation` without network packages or regex source rewriting.

Run from the repository root with the bundled host:

```powershell
& 'C:\Users\WINDOW XI\.cache\codex-runtimes\codex-primary-runtime\dependencies\native\powershell\pwsh.exe' -NoLogo -NoProfile -File 'tools/social-dev/twin-repair/twin-repair.ps1' probe
& 'C:\Users\WINDOW XI\.cache\codex-runtimes\codex-primary-runtime\dependencies\native\powershell\pwsh.exe' -NoLogo -NoProfile -File 'tools/social-dev/twin-repair/twin-repair.ps1' mirror
& 'C:\Users\WINDOW XI\.cache\codex-runtimes\codex-primary-runtime\dependencies\native\powershell\pwsh.exe' -NoLogo -NoProfile -File 'tools/social-dev/twin-repair/twin-repair.ps1' plan
& 'C:\Users\WINDOW XI\.cache\codex-runtimes\codex-primary-runtime\dependencies\native\powershell\pwsh.exe' -NoLogo -NoProfile -File 'tools/social-dev/twin-repair/twin-repair.ps1' apply --batch r2-type-canary-001
& 'C:\Users\WINDOW XI\.cache\codex-runtimes\codex-primary-runtime\dependencies\native\powershell\pwsh.exe' -NoLogo -NoProfile -File 'tools/social-dev/twin-repair/twin-repair.ps1' verify --batch r2-type-canary-001
& 'C:\Users\WINDOW XI\.cache\codex-runtimes\codex-primary-runtime\dependencies\native\powershell\pwsh.exe' -NoLogo -NoProfile -File 'tools/social-dev/twin-repair/twin-repair.ps1' reindex
& 'C:\Users\WINDOW XI\.cache\codex-runtimes\codex-primary-runtime\dependencies\native\powershell\pwsh.exe' -NoLogo -NoProfile -File 'tools/social-dev/twin-repair/twin-repair.ps1' report
```

`probe` and `plan` are non-mutating with respect to the original source roots. `mirror` writes only under the ignored R2 artifact root.

`apply` writes only to the ignored Twin, one syntax-tree batch per source file, and emits compact provenance/status evidence under the local R2 artifact root. `verify` replays the batch from the unchanged original source. `reindex` checks the Twin closure and conservatively reconciles the accepted R1.5.1 graph split; it does not invent edges from unresolved source.

The tracked canonical prework profiler is `tools/social-dev/r2_prework_probe.py`. The compact accepted closure is generated by `tools/social-dev/build_r2_acceptance.py` from the ignored local evidence.
