# Knowledge

หลักฐานและความรู้สำหรับการสร้าง simulation ใหม่ แยกจาก source/input และ runtime ที่นำไปใช้งานจริง

- `baseline/` — ขอบเขตและหลักฐานตั้งต้น
- `world-assets/` — ฉาก ห้อง เฟอร์นิเจอร์ และ asset contracts
- `characters/` — actor, identity, movement และ animation evidence
- `language/` — locale และข้อความเกม
- `reverse-engineering/` — หลักฐาน C/assembly, corpus และ contracts
- `csharp/` — C# decompiler evidence ชุดหลักและรายงาน coverage
